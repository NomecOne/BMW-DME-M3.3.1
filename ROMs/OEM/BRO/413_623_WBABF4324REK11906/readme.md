DO NOT RECOMMEND USING THIS ROM  
I have reviewed this ROM just a little bit as of 12/30/2025 and see that large areas of this rom that are usually all 
FF in others is populated with DATA. I believe that the DATA in this ROM is factory BMW patched. The ID number in the 
code is 372.08 but I am not sure if that can be trusted. There are BMW tech doc that indicated they could write to 
blank space on the chip to update/override the original code. This type modification to ROM data is not compatible with any rom reading/defining tool that we currently have. This is a good example of why it is difficult to create an editor solution that could use the stock rom out your own car.
